## 📖 Overview

This repository contains my **Week 3 Cybersecurity Internship** practical work completed as part of the **Networkwalks Cybersecurity & Ethical Hacking Program**.

The objective of this lab was to understand password attacks, password hashing, and credential security through hands-on exercises performed in a controlled and authorized laboratory environment.

---

## 🎯 Objectives

- Learn how password hashes are generated and stored.
- Perform password auditing in a lab environment.
- Understand different password attack techniques.
- Recover passwords from hashes using authorized methods.
- Analyze password security weaknesses.
- Document findings in a professional penetration testing report.
